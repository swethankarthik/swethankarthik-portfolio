## 📌 Overview

Welcome to the official source code repository for **Avvari Swethan Karthik's Personal Portfolio Website**.

This portfolio showcases my work as an **AI Engineer and Backend Systems Architect**. It highlights my internship experience at **Accenture**, **Infosys Springboard**, and **Coincent.ai**, featured AI projects (such as Text-to-Audio Music Composition with PyTorch & MusicGen, Real-time Pothole Detection with YOLOv8 & FastAPI, and NutriSync AI), technical skills, certifications, and academic background.

The application features a modern, ultra-responsive web interface powered by **custom glassmorphism styling, ambient 165Hz canvas animations, dynamic JSON data binding, zero-margin PDF vector rendering for certificates**, and an interactive **Terminal / Matrix Mode**.

---

## ✨ Features

- 🎨 **Modern Glassmorphism & Cyberpunk Aesthetics**: Custom design system utilizing sleek gradients, dynamic ambient glows, and responsive typography (Plus Jakarta Sans, Audiowide & Inter).
- 🌌 **High-Performance Ambient Canvas Background**: Particle physics and interactive background mesh rendering for high-refresh-rate displays.
- 💻 **Interactive Terminal / Matrix Mode**: Embedded CLI terminal experience letting users interact via command line prompts (`help`, `skills`, `projects`, `experience`, `clear`).
- 📄 **Zero-Margin High-DPI Vector PDF Viewer**: Integrated PDF.js engine rendering certificate PDFs directly on vector canvas modals with zoom & page controls.
- 📊 **Dynamic Data Schema Driven**: Modular decoupling of content using `assets/data/portfolio.json` for real-time portfolio updates without HTML refactoring.
- 📱 **Fully Responsive Layout**: Built with custom CSS Grid/Flexbox and optimized for all screen sizes from mobile devices to 4K displays.

## 🚀 Quick Start / Local Setup

You can run and preview this portfolio locally using any static HTTP file server.

### Option 1: Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (if not already installed).
3. Right-click `index.html` and click **"Open with Live Server"**.

### Option 2: Using Python Simple HTTP Server
If you have Python installed, open your command terminal in the root directory and run:

```bash
# Python 3.x
python -m http.server 8000
```
Then visit [`http://localhost:8000`](http://localhost:8000) in your web browser.

### Option 3: Using Node.js `npx serve`
```bash
npx serve .
```
